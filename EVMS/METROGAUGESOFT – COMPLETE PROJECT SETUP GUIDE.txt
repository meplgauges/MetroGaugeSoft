====================================================
HOW TO RUN THIS PROJECT ON NEW SYSTEM
====================================================

STEP 1:
Install .NET 8 SDK (Windows Desktop)

Verify installation:
Open Command Prompt
Type: dotnet --version
It should show 8.x.x

----------------------------------------------------

STEP 2:
Install SQL Server Express

Also install:
SQL Server Management Studio (SSMS)

Create Database:
MetroGaugeSoft

----------------------------------------------------

STEP 3:
Update Connection String

Open:
appsettings.json (or App.config)

Change SQL Server name to local machine instance.

Example:
Data Source=NEWPC\SQLEXPRESS;

----------------------------------------------------

STEP 4:
Install Mitsubishi MX Component (64-bit)

Required for:
ActUtlType64Lib (PLC Communication)

----------------------------------------------------

STEP 5:
Ensure Required DLL Files Exist

Interop.OrbitCOM.dll
OrbitLibrary.dll

If missing → Copy from original system.

----------------------------------------------------

STEP 6:
Restore NuGet Packages

Open solution in Visual Studio.

Right Click Solution → Restore NuGet Packages

OR use command:

dotnet restore

----------------------------------------------------

STEP 7:
Build Project

dotnet build

OR press CTRL + SHIFT + B in Visual Studio.

----------------------------------------------------

STEP 8:
Run Project

Press F5
OR

dotnet run

====================================================
COMMON ERRORS & SOLUTIONS
====================================================

ERROR: SQL Connection Failed
→ Check SQL Server Name

ERROR: COM Component Not Registered
→ Install Mitsubishi MX Component

ERROR: Missing DLL
→ Copy Interop.OrbitCOM.dll & OrbitLibrary.dll

ERROR: NuGet Package Missing
→ Run dotnet restore
